04. Projects

Enhancing Data Diversity & Robustness for Multi-Organ Prediction in Laparoscopic Videos

This project focuses on improving the robustness and generalization of multi-organ prediction models trained on Da Vinci laparoscopic surgical videos with limited data availability. Surgical datasets often suffer from variability in lighting, camera angles, and patient anatomy, which impacts model performance in real-world scenarios.

To address this, I applied domain adaptation techniques along with generative data augmentation (GANs/diffusion-based methods) to synthetically expand the dataset and introduce variability. These enhancements helped the model better generalize across unseen surgical conditions.

The project emphasizes solving real-world ML challenges such as data scarcity, domain shift, and model robustness, and evaluates improvements using standard metrics like Dice score and IoU.

Tech stack: Python, PyTorch/TensorFlow, OpenCV, GANs/Diffusion Models, NumPy

FileFind – Local-First AI-Powered File Retrieval Agent

FileFind is a privacy-focused AI agent that enables users to search and retrieve local files using natural language queries. Unlike cloud-based solutions, this system runs entirely on-device using local LLMs via Ollama, ensuring full data privacy.

The system interprets user queries in natural language and retrieves relevant files using semantic understanding (via embeddings/LLM reasoning). It includes a lightweight interface for real-time interaction and is designed to function efficiently without external APIs.

This project demonstrates end-to-end AI system design, combining LLM integration, local inference, and user-centric application development.

Tech stack: Python, Ollama (Local LLMs), NLP, Embeddings (optional), Streamlit/CLI, File System APIs
